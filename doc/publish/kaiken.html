MAVLink Protocol Version

The current MAVLink version is 2.3. The minor version numbers (after the dot) range from 1-255.

MAVLink Type Enumerations

FMU_TM_FLAGS

[Enum] These encode flags for FMU TM report.

Value Field Name Description
1 FMU_TM_FLAGS_TIME_VALID 0x01 Field time is valid.
2 FMU_TM_FLAGS_POS_VALID 0x02 Fields lat, lon and hdg are valid.
4 FMU_TM_FLAGS_ALT_VALID 0x04 Field alt contains valid data.
8 FMU_TM_FLAGS_ALT_GPS 0x08 GPS height is being fused as a primary height reference.
16 FMU_TM_FLAGS_PREARM_CHECK 0x10 pre-arm check status. Always true when armed

FMU_COMPONENT_STATUS

[Enum] These encode the sensors whose status is sent as part of the FMU_TM message.

Value Field Name Description
1 FMU_COMPONENT_STATUS_GYRO 0x01 gyros (both instances)
2 FMU_COMPONENT_STATUS_ACCEL 0x02 accelerometers (both instances)
4 FMU_COMPONENT_STATUS_MAG 0x04 magnetometer
8 FMU_COMPONENT_STATUS_BARO 0x08 barometer
16 FMU_COMPONENT_STATUS_GPS 0x10 GPS
32 FMU_COMPONENT_STATUS_BATTERY 0x20 Battery

FMU_FAILSAFE_FLAGS

[Enum] These encode the failsafe flags sent as part of the FMU_TM message.

Value Field Name Description
1 FMU_FAILSAFE_FLAGS_ACTION 0x01 irreversible failsafe action activated (that interrupts mission)
2 FMU_FAILSAFE_FLAGS_BATTERY 0x02 failsafe on battery issue
4 FMU_FAILSAFE_FLAGS_CRITICAL_ATTITUDE 0x04 failsafe on critical pitch or roll
8 FMU_FAILSAFE_FLAGS_OFFBOARD_LOSS 0x08 failsafe on offboard stream loss
16 FMU_FAILSAFE_FLAGS_POSITION_LOSS 0x10 failsafe on position (GPS) loss
32 FMU_FAILSAFE_FLAGS_SOFTFENCE 0x20 failsafe on softfence violation
64 FMU_FAILSAFE_FLAGS_HARDFENCE 0x40 failsafe on hardfence violation
128 FMU_FAILSAFE_FLAGS_PATH 0x80 failsafe on path acceptance radius violation

MAVLink Commands (MAV_CMD)

MAVLink commands (MAV_CMD) and messages are different! These commands define the values of up to 7 parameters that are packaged INSIDE specific messages used in the Mission Protocol and Command Protocol. Use commands for actions in missions or if you need acknowledgment and/or retry logic from a request. Otherwise use messages.

MAVLink Messages

FMU_TM ( #11103 )

[Message] (MAVLink 2) Kaiken FMU telemetry.

Field Name Type Units Values Description
time uint64_t us Time of applicability of position (microseconds since UNIX epoch).
satellites_visible uint8_t Number of satellites visible. If unknown, set to UINT8_MAX.
fix_type uint8_t GPS_FIX_TYPE GPS fix type.
hdg uint16_t cdeg Vehicle heading (yaw angle), 0.0..359.99 degrees. If unknown, set to: UINT16_MAX.
lat int32_t degE7 Latitude, expressed
lon int32_t degE7 Longitude, expressed
alt int32_t mm Altitude (MSL). Note that virtually all GPS modules provide both WGS84 and MSL.
flight_state uint8_t UTM_FLIGHT_STATE Flight state
rtcm_rate_wifi uint8_t HzE2 Rate of RTCM messages being received by WiFi
rtcm_rate_lora uint8_t HzE2 Rate of RTCM messages being received by LoRa
flags uint8_t FMU_TM_FLAGS Bitmap showing TM flags. Value of 0: not present. Value of 1: present.
component_present uint8_t FMU_COMPONENT_STATUS Bitmap showing which onboard components are present. Value of 0: not present. Value of 1: present.
component_health uint8_t FMU_COMPONENT_STATUS Bitmap showing which onboard components are operational. Value of 0: not present. Value of 1: present.
failsafe_flags uint8_t FMU_FAILSAFE_FLAGS Bitmap specifies detected failsafe. Value of 0: not present. Value of 1: present.
voltage_battery uint16_t mV Battery voltage, UINT16_MAX: Voltage not sent by autopilot
current_battery int16_t cA Battery current, -1: Current not sent by autopilot
battery_remaining int8_t % Battery energy remaining, -1: Battery remaining energy not sent by autopilot
